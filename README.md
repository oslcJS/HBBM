## overview

![](https://raw.githubusercontent.com/oslcJS/.github/main/assets/1.gif)

Removes default join and quit messages for a clean chat experience.

---

## features

![](https://raw.githubusercontent.com/oslcJS/.github/main/assets/2.gif)

- hides join messages  
- hides quit messages  
- lightweight  
- no dependencies  
- silent operation
